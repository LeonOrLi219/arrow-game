# 一箭又一箭

## 1. 项目名称

**一箭又一箭（Arrow Elimination Game）**

## 2. 游戏简介

《一箭又一箭》是一款使用 Python 和 Tkinter 开发的简单箭头消除小游戏。

游戏棋盘由多个单元格组成，每个单元格中可能存在一个指向上、下、左、右四个方向之一的箭头。

玩家点击箭头后，程序会沿箭头指向的方向检查路径：

* 如果箭头前方没有其他箭头阻挡，则箭头会飞出棋盘并被消除；
* 如果前方存在其他箭头，则认为发生碰撞，箭头不会被消除，同时扣除一次失误次数；
* 消除棋盘上的全部箭头后即可通关；
* 当失误次数降为 0 时游戏失败，可以重新开始当前关卡。

游戏包含多个关卡，并提供开始界面、游戏界面以及通关/失败界面。

## 3. 开发环境

* 编程语言：Python 3
* 图形界面：Tkinter
* 开发工具：Visual Studio Code / PyCharm 等
* 操作系统：Windows / macOS / Linux
* 第三方库：无

程序使用 Python 自带的 Tkinter 库，不需要额外安装第三方依赖。

## 4. 安装和运行方法

### 4.1 安装 Python

请先安装 Python 3。

安装完成后，在终端输入：

```bash
python --version
```

如果能够显示 Python 版本号，说明 Python 已经安装成功。

### 4.2 下载项目

可以通过 Git 克隆项目：

```bash
git clone https://github.com/你的用户名/arrow-game.git
```

进入项目目录：

```bash
cd arrow-game
```

### 4.3 运行游戏

执行：

```bash
python arrow_game.py
```

即可启动游戏。

本项目不需要执行 `pip install`，因为使用的 Tkinter 属于 Python 标准库。

## 5. 游戏操作说明

### 开始游戏

运行程序后进入开始界面，点击“开始游戏”进入第一关。

### 点击箭头

使用鼠标点击棋盘中的箭头。

程序会判断箭头指向方向上的路径：

* 路径畅通：箭头飞出棋盘并消失；
* 路径被其他箭头阻挡：箭头发生碰撞反馈，并扣除一次失误次数。

### 通关

当当前关卡中的所有箭头都被消除后，即可进入下一关。

完成所有关卡后显示通关界面。

### 游戏失败

如果连续发生阻挡，导致剩余失误次数降为 0，则游戏失败。

玩家可以点击重新开始按钮重新进行当前关卡。

### 重新开始

游戏过程中可以点击“重新开始”按钮，将当前关卡恢复到初始状态。

## 8. 核心实现思路

程序使用 `(行, 列)` 坐标表示箭头所在位置，并使用 `U、D、L、R` 表示箭头方向。

例如：

```python
DIRS = {
    "U": (-1, 0),
    "D": (1, 0),
    "L": (0, -1),
    "R": (0, 1)
}
```

点击箭头后，根据箭头方向不断检查下一格：

```text
箭头 → 下一格 → 下一格 → 下一格 → 棋盘边界
```

如果检查过程中没有遇到其他箭头，则允许箭头飞出棋盘。

如果遇到其他箭头，则判定为碰撞。

这种方法可以统一处理四个方向，不需要分别编写完全独立的检测逻辑。
